# Support

If you need support, you can contact us via:

## Email

[Email](mailto:support@revolt-studios.com){ .md-button .md-button--primary }

Please contact support using the template below. Providing detailed information will help us resolve your issue faster.

---

### 📩 Template

Copy and paste the following template when contacting support:

Subject:

```
[Domino] Short description of the issue
```

Content:

```

Engine Version:
Plugin Version:
Project Type: (Blueprint / C++ / Both)
Platform: (Windows / Linux / Mac / Other)

Issue Description:
(Please describe the issue clearly and include the expected behavior.)

Steps to Reproduce:
1.
2.
3.

Error Logs:
(Attach relevant logs or paste error messages here.)

Screenshots / Videos:
(Attach if applicable.)

Additional Information:
(Any relevant context that may help.)

Thank you.
```
