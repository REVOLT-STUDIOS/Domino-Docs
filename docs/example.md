# Example Project

To help you understand and experiment with the framework, the plugin includes an **Unreal Engine example project**.

This project demonstrates the core systems described in this documentation and provides a sandbox environment for testing systemic behaviors in isolation.

---

## What’s Included

The example project contains:

- Pre-configured Actors using Brain and Behavior Components
- Sample Actions, Reactions, and Effects
- Demonstrations of stimulus propagation (Hit, Overlap, Trace, Radius)
- Meta-Property usage examples
- State-driven interactions using Brain global flags
- Intensity accumulation and threshold-based activation setups

Each setup is intentionally designed to showcase a specific aspect of the framework in a clear and isolated manner.

---

## Sandbox Environment

The project also includes a dedicated **sandbox level**.

This level allows you to:

- Trigger stimuli manually
- Observe propagation in real time
- Test different flag combinations
- Experiment with intensity thresholds
- Analyze systemic interactions without scripted logic

The sandbox is intended as a safe space for experimentation and rapid prototyping.

---

## Recommended Workflow

When learning the framework:

1. Open the example level.
2. Inspect Actors with Brain and Behavior Components.
3. Review their configured Actions and Reactions.
4. Use debugging tools (Gameplay Debugger / Visual Logger).
5. Modify parameters and observe how the system reacts.

The best way to understand the plugin is to experiment with it directly.

---

## Purpose

The example project is not meant to represent a full game implementation.  
Its purpose is purely educational and demonstrative to illustrate how systemic interactions can be composed using the framework.
